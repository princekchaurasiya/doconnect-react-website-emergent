# Google Search Console — after go-live

1. Open [Google Search Console](https://search.google.com/search-console).
2. Select property **doconnect.org** (or add if missing).
3. **Sitemaps** → enter: `https://www.doconnect.org/sitemap.xml` → Submit.
4. **URL Inspection** → test `https://www.doconnect.org/doctor-home-visit-mumbai`.
5. Monitor **Pages** for old `.php` URLs; `.htaccess` 301s should consolidate traffic.
